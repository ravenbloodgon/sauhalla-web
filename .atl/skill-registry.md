### RULES:react-vite — matches `src/**/*.jsx`, `src/**/*.js`

- React 19 + Vite 7, plain JSX (no TypeScript). ESM only (`"type": "module"`).
- Function components, named default export per file. One component per file in `src/components/`.
- No CSS-in-JS, no Tailwind, no UI library. All styles live in `src/styles/styles.css`,
  addressed by semantic class names. Design tokens are CSS custom properties on `:root`.
- Content that varies (links, prices, product specs, nav items, copy lists) belongs in
  `src/data/site.js` as named exports — never hardcoded in JSX.
- External links carry `target="_blank" rel="noopener noreferrer"`; internal anchors
  (`#…`) and `mailto:` must not. `SplitSection.jsx` has a `linkTarget()` helper for this.
- Accessibility is load-bearing: every `<section>` has `aria-labelledby` pointing at its
  heading, decorative media blocks use `role="img"` + `aria-label`, the nav toggle keeps
  `aria-expanded` in sync. Do not regress these.
- Respect `prefers-reduced-motion` for any new animation.
- Yarn 4 with `nodeLinker: node-modules`. Use `yarn`, never `npm`.

### RULES:css — matches `src/styles/*.css`

- Single stylesheet, appended by section with a `/* ---------- name ---------- */` banner.
- Use existing tokens (`--bg`, `--surface`, `--text`, `--muted`, `--line`, `--accent`,
  `--serif`, `--sans`, `--radius`, `--maxw`). Add a token rather than a hardcoded hex.
- Breakpoints already in use: 960px, 760px, 520px. Reuse them, don't invent new ones.
- Layout with grid/flex; `.wrap` provides the max-width container.

### RULES:verify — matches any change

- There is no test runner and no ESLint config, despite a `lint` script in package.json.
  Do not claim tests or lint passed. Flag the gap instead.
